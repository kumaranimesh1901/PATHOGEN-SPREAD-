# Predictive Modeling for Pathogen Spread: Accuracy vs Public Safety

An AI-powered epidemiological outbreak forecasting system that integrates mathematical compartmental models (SEIR) with deep learning (LSTM) in a weighted hybrid predictive framework. The system includes Explainable AI (SHAP), algorithmic fairness auditing (Fairlearn), a custom 0-100 Ethical Outbreak Risk Score, and a Public Safety Alert Engine, all interactive through a professional, premium Streamlit dashboard.

---

## Technical Stack

- **Core Language**: Python 3.11+
- **Epidemiology**: `scipy` (solving ordinary differential equations via `odeint`)
- **Deep Learning**: `tensorflow/keras` (multi-layer LSTM)
- **Machine Learning & Fairness**: `scikit-learn`, `fairlearn` (demographic parity & equalized odds)
- **Explainability**: `shap` (surrogate TreeExplainer)
- **Visualization & UI**: `streamlit`, `plotly`, `matplotlib`, `seaborn`
- **Serialization**: `joblib`, `json`

## Outbreak Risk Formula

The **Ethical Outbreak Risk Score** (0-100) integrates four distinct components:
1. **Outbreak Severity (40%)**: Daily forecasted cases relative to population.
2. **Vulnerability (20%)**: Population density (log-scaled).
3. **Uncertainty Penalty (15%)**: Active model forecasting error ($1 - \text{Confidence}$). High uncertainty drives precautionary risks.
4. **Healthcare Capacity Buffer (25%)**: Available beds per 1000 people. Low capacity spikes risk.

$$\text{Risk Score} = 0.40 \cdot \text{Severity} + 0.20 \cdot \text{Density} + 0.15 \cdot \text{Uncertainty} + 0.25 \cdot \text{Capacity Vulnerability}$$

## Getting Started

### 1. Installation

Create a virtual environment (optional but recommended) and install dependencies:

```bash
# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install requirements
pip install -r requirements.txt
```

### 2. Execution

To run the end-to-end training pipeline (generates the dataset, trains the LSTM and SEIR models, calculates SHAP plots, and performs fairness audits):

```bash
python train.py
```

### 3. Launch Dashboard

Run the Streamlit interactive dashboard to browse the results:

```bash
streamlit run dashboard/app.py
```

## Features Displayed on the Dashboard

1. **Dataset Overview**: Detailed dataset statistics, sample table, and feature correlation matrix.
2. **Historical Trends**: Visualizes active cases, deaths, recoveries, and mobility drops during lock-downs.
3. **SEIR Forecast**: Fits $\beta$, $\sigma$, $\gamma$, and computes the Reproduction Number ($R_0$) for the country.
4. **LSTM Forecast**: Renders predictions generated by the deep learning LSTM network.
5. **Hybrid Forecast**: Adjust weights dynamically ($w_{\text{seir}} \times SEIR + w_{\text{lstm}} \times LSTM$) and view real-time scorecard updates (MAE, RMSE, MAPE).
6. **SHAP Explanations**: View global feature importance, local waterfall breakdowns, and force contribution vectors.
7. **Bias Analysis**: Displays Fairlearn group performance metrics by country and the overall Bias Score category.
8. **Ethical Risk Score**: Simulate how variables (predicted cases, density, confidence, capacity) dynamically shift the Risk Score.
9. **Public Safety Alerts**: Real-time alerts (LOW RISK, MODERATE RISK, HIGH RISK, CRITICAL) mapping scores to action protocols.
